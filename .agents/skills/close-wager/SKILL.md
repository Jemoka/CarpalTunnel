# Close a wager

Read sections 5–7 of [Place a wager](../place-wager/SKILL.md). Verify the existing runs and artifacts, compare them with the declared decision rule, then update the bet, owning project and configured review. Report missing evidence explicitly. Closing a wager provides no authority to start or restart an experiment.

After scientific closure and confirmed merge, follow the configured branch cleanup policy for this wager. Keep pending review or cleanup visible in the handoff.
